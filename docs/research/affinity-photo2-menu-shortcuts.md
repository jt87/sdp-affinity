# Affinity Photo 2: menu shortcuts

Source: live menus of Affinity Photo 2 version 2.6.5 (Mac App Store build), read with System Events on 2026-10-07. These are the defaults on this machine, assuming none were customized.

Caveats: menus show the persona that was active when read, so persona-specific items may be missing. Single-key tool shortcuts (V, P, B…) are not menu items; see the official v2 help page. Apple-menu, Window > Move & Resize and dictation/emoji items are omitted.

Modifiers: ⌃ Control, ⌥ Option, ⇧ Shift, ⌘ Command.
